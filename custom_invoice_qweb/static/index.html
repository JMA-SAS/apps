Factura Personalizada QWeb

Versión: 16.0

Autor: Luis Felipe Paternina

Categoría: Contabilidad

Descripción

Este módulo permite generar facturas con un diseño personalizado tipo imagen, utilizando QWeb.

Características

  • Generación de facturas visualmente personalizadas.
  • Diseño adaptable basado en una imagen o plantilla específica.
  • Fácil instalación e integración con el módulo account.

Instalación

  1. Copiar el módulo en la carpeta de addons.
  2. Actualizar la lista de aplicaciones.
  3. Instalar desde el backend de Odoo.

Dependencias

Este módulo depende de:

  • account
