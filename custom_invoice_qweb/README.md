# Factura Personalizada QWeb

Este módulo para Odoo permite generar facturas (`account.move`) con un diseño personalizado, simulando una plantilla de tipo imagen.

## 🧾 Descripción

El módulo reemplaza el diseño estándar de las facturas con una versión visualmente personalizada, adaptada a una imagen o diseño gráfico específico, utilizando la tecnología QWeb de Odoo para la generación de PDF.

## 🛠️ Características

- Generación de facturas con diseño basado en imagen personalizada.
- Implementado utilizando plantillas QWeb.
- Integración con el módulo `account` de Odoo.

## 📂 Archivos Incluidos

- `report/report_templates.xml`: Define las plantillas personalizadas para la factura.
- `report/invoice_report.xml`: Configura el reporte de facturas utilizando la plantilla personalizada.

## 🧩 Dependencias

Este módulo depende del módulo `account`.

## 🚀 Instalación

1. Copia este módulo en tu carpeta de addons personalizados.
2. Activa el modo desarrollador en Odoo.
3. Actualiza la lista de aplicaciones.
4. Instala el módulo “Factura Personalizada QWeb”.
