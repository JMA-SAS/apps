⏰ Server Time Check

Consulta la hora del Servidor, Odoo y PostgreSQL en un solo lugar

Este módulo añade un menú en Odoo para visualizar tres referencias de tiempo clave:

  • Hora del Servidor: obtenida desde el sistema operativo.
  • Hora de Odoo: generada con fields.Datetime.now().
  • Hora de PostgreSQL: consultada mediante SELECT NOW().

✨ Características principales

  • Menú dedicado dentro de Odoo.
  • Modelo transitorio para evitar acumulación de registros.
  • Seguridad configurable mediante grupos de usuarios.
  • Compatible con Odoo 17 Community y Enterprise.
