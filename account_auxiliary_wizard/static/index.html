Asistente de Balance Auxiliar

Este módulo permite generar vistas previas filtradas del balance auxiliar contable, incluyendo opciones para agrupar por cuentas, terceros, excluir saldos en cero, y más.

Funcionalidades

  • Selección entre reporte de Resumen o Detalle.
  • Filtrado por fechas, cuentas y terceros.
  • Opción para agrupar por cuenta, por tercero, o ambos.
  • Conversión de saldos a la moneda de la compañía.
  • Vista previa en árbol (vista tipo tree) desde el wizard.

Modelo principal

account.auxiliary.wizard: modelo transitorio (wizard) que controla la lógica de filtros y parámetros para la vista del balance auxiliar.

Vista previa generada

La acción preview_html devuelve una ventana emergente con las líneas contables filtradas mediante vista tipo árbol.

Requisitos

  • Odoo 17 (compatible con modelos estándar de contabilidad).
  • Dependencias: account.

Acción de Confirmación

El botón de confirmación lanza una notificación al usuario con el mensaje: Se ha confirmado el balance.
