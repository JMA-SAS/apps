# Factura Autoenvío

Este módulo de Odoo 16 permite que las **facturas de cliente** (`account.move`) se envíen automáticamente al cliente por correo electrónico en el momento en que son **validadas**.

## 🚀 Características

- Envío automático de facturas al validar.
- Uso de la plantilla de correo estándar de Odoo o una personalizada.
- Integración total con `account` y `mail`.
- Reducción de pasos manuales en el flujo de facturación.

## 📦 Instalación

1. Clonar este repositorio en tu carpeta de addons.
2. Actualizar la lista de aplicaciones en Odoo.
3. Instalar el módulo **Factura Autoenvío**.

## ⚙️ Configuración

- Asegúrate de tener configurado un servidor de correo saliente en Odoo.
- Personaliza la plantilla de correo `Email Template: Invoice` si deseas modificar el formato del envío.
